# BELOW PROTOCOL — новый игровой срез

Cloudflare: https://beneath-byz.pages.dev/
GitHub: https://github.com/maksutenkox/Beneath
Telegram: https://t.me/BeneathhBot

## Реализовано

Проект переведён с изометрического убежища на вертикальный 2D side-view action-platformer. Рабочий срез включает офисный HUB, процедурные боевые этажи, платформенное движение, камеру, HP, оружие-клавиатуру, тренировочный манекен, верстак, переходы между этажами и сохранение версии 4.

Устаревшие изометрические персонажи, NPC, сектора, двери, ресурсы, ремонт, population simulation и их тесты удалены после проверки импортов. Telegram/browser adapters, аудио, локальное сохранение, GitHub и Cloudflare Pages сохранены.

## Графика

- героиня: `src/game/assets/below-protocol/heroine-side.png`, 768×560, 8×5 кадров с единым source scale;
- окружение HUB: `src/game/assets/below-protocol/hub-props.png`, 512×512, 4×4 объектов;
- офисные фоны: `src/game/assets/below-protocol/office-backdrops.png`, 1024×512, восемь модулей;
- заражённый сотрудник: `src/game/assets/below-protocol/office-zombie.png`, 768×448, 8×4 кадров;
- подготовка: `scripts/prepare-below-protocol-assets.cjs`;
- runtime использует nearest-neighbor и не требует image-processing зависимостей.

Главная героиня — взрослая рыжеволосая офисная сотрудница в оливковой куртке, синих джинсах и ботинках. Первый ближний бой выполняется потрёпанной клавиатурой. Направление и серьёзные пропорции основаны на пользовательском визуальном референсе; изометрические кадры не переиспользованы.

## Генерация

Использован встроенный imagegen с пользовательским референсом. Промпт героини требовал side-view production sheet: взрослая анатомия, медно-рыжий хвост, оливковая куртка, синие джинсы, idle/run/jump/keyboard attack/interact/hurt/death, 8 кадров на ряд, прозрачный фон, без chibi. Промпт окружения требовал 4×4 side-view atlas корпоративного аварийного HUB: верстак, манекен, лифт, лестница, стол, сервер, принтер, кулер, шкаф, растение, баррикада, коробки, свет, вентиляция, монитор и кабели.

Сгенерированная шахматная подложка удалена при offline-подготовке. Героиня пересобрана без индивидуального `fit inside`: одинаковый коэффициент сохраняет реальный рост между кадрами. Фоны и враг нарезаны в строгие атласы и визуально проверены в браузере.

## Проверка

17 автоматических проверок покрывают HUB, процедурную детерминированность, платформенные коллизии, движение, камеру, анимации, melee, зомби, получение урона, сердца, взаимодействие, ввод, save v4, размеры атласов и portrait Telegram shell.

В этот этап намеренно не входят боссы, другие типы врагов, NPC и сюжет.
