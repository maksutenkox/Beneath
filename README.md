# Below Protocol

Вертикальный Telegram Mini App в формате 2D action-platformer / roguelike. Текущая сборка включает безопасный корпоративный HUB, процедурные офисные этажи и первый законченный боевой цикл.

## Текущий игровой срез

- портретный экран 9:16 и управление, рассчитанное на одну руку;
- движение влево/вправо с ускорением, торможением и контролем в воздухе;
- переменная высота прыжка, coyote time 100 мс и jump buffer 110 мс;
- плавная боковая камера с dead zone, look-ahead и ограничением карты;
- рыжеволосая героиня в оливковой куртке и синих джинсах;
- анимации idle, run, jump, fall, land, attack, interact, hurt и death;
- единый масштаб и линия стоп во всех кадрах героини без «пульсации» при беге;
- три сердца с поддержкой половины сердца;
- первое оружие — потрёпанная клавиатура; верстак меняет модификацию и улучшает её;
- безопасный HUB с рабочим местом, техникой, тренировочным манекеном и дверью в офисы;
- процедурные офисные этажи с разной длиной, фонами, препятствиями, платформами и размещением врагов;
- первый враг — заражённый офисный сотрудник с преследованием, атакой, получением урона и смертью;
- локальное сохранение этажа, позиции, HP, состояния врагов, оружия, улучшений и громкости;
- отдельные Game Core и Telegram/browser adapters — основу можно перенести в Android-оболочку.

Боссы, другие типы врагов, дружелюбные NPC и сюжет намеренно не входят в этот этап.

## Запуск

```powershell
npm run dev
```

Откройте `http://127.0.0.1:4173`. На компьютере: `A/D` или стрелки — движение, `Space/W` — прыжок, `J` или левая кнопка мыши — атака, `E` — взаимодействие.

## Проверка

```powershell
npm run check
npm test
```

## Архитектура

- `src/game/core` — игровой цикл и сериализуемое состояние;
- `src/game/player`, `physics`, `camera` — переносимые движение, коллизии и камера;
- `src/game/combat`, `health`, `interaction` — минимальные расширяемые системы;
- `src/game/map/HubMap.js` — геометрия и содержимое безопасного HUB;
- `src/game/map/OfficeLevelGenerator.js` — детерминированная генерация боевых этажей;
- `src/game/enemy` — поведение и состояние заражённых сотрудников;
- `src/game/rendering` — side-view pixel-art renderer и sprite atlases;
- `src/game/save` — версионированное сохранение без зависимости от Telegram;
- `src/platform` — Web Audio, HUD и адаптеры браузера / Telegram Mini App.

Pixel-art выводится с nearest-neighbor без размытия. Исходный Telegram Bot API token не хранится в клиенте или репозитории: привязка меню выполняется локальным скриптом через переменную `TELEGRAM_BOT_TOKEN`.
